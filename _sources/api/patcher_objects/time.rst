``.transport``
--------------

Starts, stops and sets the tempo of a named domain clock, creating the clock (stopped) if it does not exist yet. A bang sends the clock's beat position and tempo.

:Dart: ``Obj.gTransport``
:Kind: Control-rate

**Inlets**

.. list-table::
   :header-rows: 1
   :widths: 6 18 18 18 40

   * - #
     - Label
     - Accepts
     - Range
     - Description
   * - 0
     - control
     - FLOAT, INT, BANG, LIST
     - 0 or 1, bang, 'start', 'stop', 'tempo <bpm> [<ramp>]'
     - A non-zero number or 'start' starts the clock; 0 or 'stop' stops it. 'tempo <bpm> [<ramp>]' sets the tempo. A bang sends the tempo and the beat position.
   * - 1
     - tempo
     - FLOAT, INT
     - BPM
     - The tempo in BPM. Applied at once while running, kept for the next start while stopped.
