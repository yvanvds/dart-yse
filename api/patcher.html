Patcher#

Modular Max/MSP-style DSP / event graphs. A Patcher owns a collection of PHandle-shaped objects wired together by inlets and outlets. The graph can be built programmatically, driven from Dart code, serialised to JSON, and replayed.

Upstream: api/patcher.html / api/patcher.html / api/patcher.html.

For an end-to-end walk-through, see Patcher: modular synthesis in code. The list of object types createObject accepts is on the Patcher object reference reference page.

Patcher#

Patcher#

class Patcher implements Finalizable

Modular DSP/event graph (Max/MSP-style patcher).

Build a graph programmatically with [createObject] + [connect], or load one from a JSON dump via [parseJson]. Drive it directly with [passBang] / [passInt] / [passFloat] / [passString] into named .r (Obj.gReceive) objects, listen to what it sends back out on [messages], or hand it to a [Sound] via [Sound.fromPatcher] to use it as an audio source.

Throws [YseException] if the engine rejects the configuration (e.g. a negative [mainOutputs], or a [name] longer than [maxNameLength]).

Properties#

Pointer<YsePatcher> get handle

Internal: native handle (used by Sound.fromPatcher).

String get name

set name(String? value)

The patcher’s name, which scopes every bus slot inside it.

Every patcher has one: an unnamed patcher gets an auto-generated patcher_<N>. A .s (Obj.gSend) object with slot x in a patcher named foo publishes to patcher.foo.x, and a .r (Obj.gReceive) with slot x hears a [Bus.publish] to patcher.foo.x. Note the patcher. prefix: host code addressing a patcher slot must add it.

Setting null or ‘’ restores the auto-generated name. Renaming re-anchors every slot under the new name. Names are not unique: two patchers with the same name share their slots and stores.

The name can be set before the engine is initialised; it is applied at init. It is saved by [dumpJson] and applied by [parseJson] unless a name was already set.

Throws [YseException] (invalidArgument) for a name longer than [maxNameLength] characters; the current name is kept.

int get objects

Number of objects in the patcher.

Stream<PatcherMessage> get messages

Broadcast stream of the messages this patcher sends to the host.

A message arrives here when it is sent to a name that no `.r` (`Obj.gReceive`) in this patcher receives: a .s (Obj.gSend) inside the patch, or a [passBang] / [passInt] / [passFloat] / [passString] call with nothing listening. [PatcherMessage.address] is that name — the .s argument or the pass* target — not the patcher.<name>.<slot> bus address (a .s also publishes there; see [name] and Bus).

The native send callback is installed when the first listener subscribes and cleared when the last one cancels. While it is installed, pass* returns true even for a name nothing receives (see [passBang]). Listening before the engine is initialised is fine: the callback takes effect at init.

## Threading

The engine calls the native callback synchronously on whichever thread emitted the message — the control thread for a pass* or a [PHandle] send* that drives a .s, but an engine worker thread for a timer-driven one (a millisecond .metro feeding a .s). Never the audio thread. Because it can run off the control thread, the bridge is a NativeCallable.listener: each call is posted to this isolate and delivered from its event loop, so listeners never run inside an engine callback and may call back into the patcher freely. Even a message from a pass* on this isolate is therefore delivered asynchronously, after the call returns. Each message’s native strings are copied and released exactly once, including messages still in flight when the stream is torn down.

## Lifecycle

[dispose] and System.close() clear the callback and close the stream (listeners get onDone). After System.close(), read [messages] again for a fresh stream. Reading it on a disposed patcher throws [StateError].

PHandle createObject(String type, {String args = ''})

Add an object of [type] to the patcher (see [Obj] for constants).

[args] is the creation argument string (object-specific format). The returned [PHandle] is owned by the patcher — release with [deleteObject], never directly.

void deleteObject(PHandle obj)

Remove [obj] from the patcher.

Deleting a subpatcher (an [Obj.patcher] object) also deletes everything inside it, transitively — nested subpatchers and their contents included. Any [PHandle] you still hold that pointed inside the deleted group is dangling afterwards: do not use it.

void clear()

Remove every object from the patcher.

void setContainer(PHandle obj, PHandle? container)

Put [obj] inside the subpatcher [container], or move it back to the top level when [container] is null.

A subpatcher is an object of type [Obj.patcher]. It is not a separate [Patcher]: create its contents with [createObject] on this patcher, then move them inside with this call. Its pins are the boundary objects among its direct contents — .inlet / ~inlet ([Obj.gInlet] / [Obj.dInlet]) and .outlet / ~outlet ([Obj.gOutlet] / [Obj.dOutlet]), whose one creation argument is the pin index. Message and signal boundaries share one index space per side. Subpatchers nest.

Containment is addressing, not storage: nested objects stay in this patcher’s one flat graph, so nesting costs the audio thread nothing. Moving an object changes no connection, so place objects before you [connect] to the subpatcher’s pins.

Throws [ArgumentError] when [obj] or [container] belongs to another patcher. Throws [YseException] when the engine refuses the move — [container] is not an [Obj.patcher] object, or the move would put a subpatcher inside itself or one of its own descendants. A refused move changes nothing.

void connect(PHandle from, {required int outlet, required PHandle to, required int inlet})

Connect [from]’s [outlet] to [to]’s [inlet].

Either end may be a subpatcher ([Obj.patcher] object): the pin number is resolved to the boundary object inside it that claims that index, and the connection is recorded straight to that boundary object (so walking the graph or [dumpJson] reports the boundary object’s ID). Connecting to a pin no boundary object claims is refused.

void disconnect(PHandle from, {required int outlet, required PHandle to, required int inlet})

Remove the connection from [from]’s [outlet] to [to]’s [inlet].

A subpatcher end resolves through its boundary objects as in [connect].

void parseJson(String content)

Loading adds to the current graph: objects already in the patcher are kept and the loaded ones are created next to them. Call [clear] first to replace the patch.

Throws [YseException] if [content] is malformed JSON or not a patch. A failed load is rolled back: the patcher is left exactly as it was.

PHandle#

A PHandle is the wrapper’s view of one object inside a Patcher. The handle is owned by the patcher — destruction is through Patcher.deleteObject(), never by letting the handle go out of scope. Use PHandle to inspect an object’s structure (type, inlets, outlets), walk its outgoing connections, push messages straight to one of its inlets, and read or write its GUI metadata.

String get guiValue

The object’s whole live GUI state as one string — what a host polls to draw the control. For a scalar control (.slider, .i, .f, .dial, .incdec, .t) that is its value; for a structured one (.multislider, .rslider, .matrixctrl, …) it is every cell, space separated, in index order. Empty for an object with no GUI state.

This is the coherent read: one engine call, one snapshot. The per-cell reads ([guiValueCount], [guiValueAt]) are sampled one call at a time and may mix cells from before and after an edit.

A poll may be destructive: .b reports a pending press and clears it. Per object, poll either this getter or the per-cell reads once per frame — never both, or a consume-on-read object reports its event to one and not the other.

When [guiValueIsSettable] is true, [restoreGuiValue] with this string puts the state back. Not to be confused with [getGuiProperty], which is editor decoration persisted with the patch, not live state.

int get guiValueCount

How many cells the object’s GUI state has: 1 for a scalar control, the bank size for a .multislider, and so on. Objects without GUI state still answer 1 (their single cell is empty).

The count can change between this read and a following [guiValueAt] (a list on inlet 0 resizes a .multislider); a read past the end answers the empty string rather than failing.

bool get guiValueIsSettable

Whether this object accepts its own GUI state back on inlet 0: true when [restoreGuiValue] restores what [guiValue] read and [setGuiValueAt] writes one cell.

false for objects that predate the protocol, and deliberately for .b, whose value is a consume-on-read press — an event a restore could only replay.

GUI controls#

An editor draws a control by polling its GUI value, a list of string cells. Scalar controls (.slider, .i, .f, .dial, .incdec, .t) have one cell; structured ones (.multislider, .rslider, .matrixctrl, .kslider, .function, .xyslider, .umenu, …) have several.

  • Read the whole state with PHandle.guiValue — one engine call, one coherent snapshot, cells space separated.

  • Read one cell with PHandle.guiValueCount and PHandle.guiValueAt(). These are sampled one call at a time and are not atomic across cells (an edit can land between two reads, and the count can change), so use guiValue when coherence matters. A read past the count answers ''.

  • Write — there is no setter, by design. State goes back in as an ordinary message on inlet 0, passing the object’s own clamps and outlet sends. PHandle.restoreGuiValue() sends a saved guiValue string back; PHandle.setGuiValueAt() sends set <index> <value> (on .textedit, whose one cell is free text, the value is sent as the whole state instead). Both require PHandle.guiValueIsSettable and are thin wrappers over sendList(0, ...).

Polls can be destructive: .b reports a pending press and clears it, which is also why .b is not settable. For a given object, poll either the whole-state read or the per-cell reads once per frame, never both. Cell strings are engine-formatted (zero reads 0.); parse them rather than comparing text.

GUI properties (PHandle.getGuiProperty() / PHandle.setGuiProperty()) are a different thing: editor decoration such as geometry or colour, opaque to the engine and persisted with the patch under the "gui" key of Patcher.dumpJson(). They are not live control state.

All of these are synchronous engine calls on the isolate that called System.init(); none involves a callback.

Host I/O#

A patcher talks to the host three ways:

  • In, by name — Patcher.passBang(), passInt, passFloat and passString deliver a value to every .r (Obj.gReceive) object with that name in the patcher.

  • Out, by name — Patcher.messages is a broadcast stream of every message the patcher sends to a name no .r in it receives: a .s (Obj.gSend) in the patch, or a pass* call with nothing listening. Each PatcherMessage carries that name and a BusValue (lists arrive as a BusString). The native callback is installed on the first listen and cleared on the last cancel; while it is installed, pass* returns true even for a name nothing receives.

  • The bus — in a patcher named foo, a .s x also publishes to patcher.foo.x and a .r x hears a Bus.publish() to that address. See Bus.

The engine calls the send callback on whichever thread emitted the message: the control thread for a pass* or a PHandle.send*, an engine worker thread for a timer-driven one (a millisecond .metro), never the audio thread. The wrapper therefore bridges it with a NativeCallable.listener: messages are queued to the isolate and delivered asynchronously from its event loop, so listeners may call back into the patcher. Every native message block is freed exactly once, including messages still in flight when Patcher.dispose() or System.close() tears the stream down.

Registry introspection#

Read-only access to the engine’s patcher object registry — the same in-code documentation that drives the Patcher object reference reference. PatcherRegistry#

class PatcherRegistry

Read-only registry of every patcher object type the engine knows about.

The registry is the introspection surface behind the engine’s own patcher reference: it enumerates the object types [Patcher.createObject] accepts and, per type, the documentation metadata (description, category, and the inlet / outlet / parameter schema). Use it to build a node palette or generate documentation without hard-coding the catalogue.

All members are static; there is a single process-wide registry.

Threading: main-thread only, and not real-time safe — never call from the audio callback (CLAUDE.md Boundaries). The engine builds its metadata cache lazily on the first call and keeps it for the life of the process.

Object type constants#

The constants on Obj are the string identifiers that Patcher.createObject() accepts. There is one for every type in the engine registry, named after the upstream YSE::OBJ constant (D_SINE becomes dSine), and Obj.all lists them. Pass the constant or pass the raw string literal — they are interchangeable.

The class is generated by tool/gen_obj_constants.dart from the registry of the bound libyse and upstream pObjectList.hpp; rerun it after an engine update (--check reports a stale file).

Every constant on this class is the literal string the engine recognises, e.g. Obj.dSine == '~sine'. The ~ / . prefix convention is the same as upstream: ~ marks audio-rate (DSP) objects, . marks control-rate (event) objects.

Refer to Patcher object reference for the full per-object documentation (inlets, outlets, parameters, ranges).

Obj#

class Obj

Compile-time string identifiers for patcher object types.

Pass any of these to [Patcher.createObject] instead of a raw string literal; the two are interchangeable. The ~ prefix marks DSP / audio-rate objects, . marks control-rate objects. Every type in the engine registry has a constant, named after its YSE::OBJ constant in upstream patcher/pObjectList.hpp (D_SINE becomes [dSine]).

[all] lists every constant. For the full per-object schema (inlets, outlets, parameters) use [PatcherRegistry].

.bangbang: Sends a bang out every outlet, right to left, whatever arrives. Each outlet’s branch finishes before the next outlet fires, so it orders ‘do this, then that’.

static const String gBondo

.bondo: Holds one value per inlet and sends all of them, right to left, whenever any inlet receives one. Keeps a set of related values together, so nothing downstream sees half an update.

static const String gBuddy

.buddy: Waits until every inlet has received a value, then sends them all at once, right to left, and starts waiting again. Use it to assemble one event from parts that arrive separately.

static const String gIf

.if: Tests a condition and sends one message when it is true and, optionally, another when it is false: ‘$i1 > 64 then bang else out2 $i1’. The condition and the message items use the .expr language.

static const String gLoadbang

.loadbang: Sends a bang when the patch it is in has finished loading, so a saved patch can set up its own starting state. A bang at the inlet sends one by hand.

static const String gLoadmess

.loadmess: Sends its arguments as a message when the patch it is in has finished loading, such as ‘.loadmess 0.5’ to set a gain. A bang at the inlet sends it by hand.

static const String gMatch

.match: Watches a stream of numbers and sends the last few as a list when they match the pattern in its arguments. The word ‘nn’ matches any number, so ‘.match 1 nn 3’ sends ‘1 5 3’ after 1, 5, 3.

static const String gNext

.next: Tells the first message of a burst from the rest: a bang leaves the left outlet when a message starts a new logical event, and the right outlet when it belongs to the same event as the message before it.

static const String gOnebang

.onebang: A one-shot: lets one message through as a bang from the left outlet, then sends every further message out the right outlet until the right inlet re-arms it.

static const String gTrigger

.trigger: Sends its input out every outlet, right to left, converted per outlet to an int, a float, a bang, a list or text, or replaced by a constant. Use it to make the order of two branches explicit.

static const String gUzi

.uzi: Sends a burst of bangs at once, each preceded by its index, then a carry bang when the run is done. The patcher’s loop: ‘.uzi 16’ runs sixteen iterations inside one message.

static const String gAppend

.append: Puts a stored message after every message that arrives and sends the result as one list. Use it to add fixed trailing arguments, such as a channel number, to a computed value.

static const String gIter

.iter: Sends the items of a list out one at a time, first to last, so objects that take single numbers can process each one. A bang sends the last list again.

static const String gJoin

.join: Joins the messages held by several inlets into one list, end to end. Unlike .pack, each inlet holds a whole message of any length. .unjoin splits a list the other way.

static const String gListfunnel

.listfunnel: Sends each item of a list out as a two-item list: its index, then the item. Use it to address items by position with .route, .sel or .spray.

static const String gPack

.pack: Combines values arriving at separate inlets into one list, one element per inlet. Each creation argument sets an element’s type and starting value. Only the leftmost inlet sends the list; .pak sends from every inlet.

static const String gPak

.pak: Combines values arriving at separate inlets into one list, and sends the list whenever any inlet receives a value. Otherwise the same as .pack.

static const String gPrepend

.prepend: Puts a stored message in front of every message that arrives and sends the result as one list. Use it to put a selector word such as ‘note’ or ‘set’ in front of a computed value.

static const String gSubstitute

.substitute: Replaces every item of a message that equals the match with the replacement, anywhere in the message. A message with a replacement leaves the left outlet; one with no match leaves the right outlet unchanged.

static const String gUnjoin

.unjoin: Splits a list into groups of equal size, one group per outlet, and sends whatever is left over out the rightmost outlet. Nothing is dropped. The reverse of .join.

static const String gUnpack

.unpack: Splits a list into its items and sends each one out its own outlet, right to left. Each creation argument sets an outlet’s type and starting value. The reverse of .pack.

static const String gZl

.zl: A list processor with 31 modes: measure, reorder, pick from, search, compare, combine, accumulate or sum a list. The mode word is the first argument and can be changed with ‘mode <name>’.

static const String gAtoi

.atoi: Converts a message into the character codes of its text and holds them: ‘hi’ gives 104 105. A bang sends the held codes again, and the other two inlets add to them or replace them without sending.

static const String gCombine

.combine: Joins the items held in its inlets into one symbol, with nothing between them. Each creation argument is an item and the starting value of its own inlet. By default inlet 0 sends and the other inlets only store.

static const String gFromsymbol

.fromsymbol: Splits a symbol on its separator into a message: with separator /, voice/3/freq becomes ‘voice 3 freq’. A result that is one number or the word bang leaves as an int, a float or a bang. The inverse of .tosymbol.

static const String gItoa

.itoa: Converts character codes into the text they spell and holds it: 104 105 gives ‘hi’. A bang sends the held text again, and the other two inlets add to it or replace it without sending. The inverse of .atoi.

static const String gRegexp

.regexp: Matches messages against a regular expression. Each match leaves with its capture groups, an optional substitution rewrites every match, and a message that does not match leaves the rightmost outlet unchanged.

static const String gSpell

.spell: Spells a message out as the character codes of its text, sent as one list: ‘hi’ gives 104 105. Optional arguments pad a short result to a minimum length with a fill code.

static const String gSprintf

.sprintf: Builds a message from a format with printf-style placeholders: ‘.sprintf /voice/%d/freq’ sends /voice/3/freq for a 3. Each placeholder has its own inlet; inlet 0 formats and sends, the others only store.

static const String gTolower

.tolower: Converts the letters A-Z in a message to lower case and leaves everything else as it was: other characters, spacing and tokens. Put it in front of a .route or .sel to make the match ignore case.

static const String gTosymbol

.tosymbol: Joins the tokens of a message into one symbol, with the separator between them: with separator /, ‘voice 3 freq’ becomes voice/3/freq. A number or a bang becomes the text that spells it.

static const String gToupper

.toupper: Converts the letters a-z in a message to upper case and leaves everything else as it was: other characters, spacing and tokens. The mirror of .tolower.

static const String gBag

.bag: Holds a collection of numbers that a patch adds to and removes from, such as the notes currently held down. A bang sends every number, newest first.

static const String gCapture

.capture: Records every value that reaches it, in arrival order, so a patch can be run and then asked what went past. When full, the oldest item makes room for the newest.

static const String gColl

.coll: Stores messages at number or symbol addresses and sends them back on request: presets, note tables, cue lists. All .coll objects with the same name share one collection.

static const String gFunbuff

.funbuff: Stores (x, y) pairs of ints sorted by x, and sends the y for any x: the stored y, or the one at the nearest lower x. ‘interp’ interpolates between points; ‘next’ steps through them in order.

static const String gTable

.table: A fixed-size array of ints addressed by index, for wavetables, curves and step sequences. It can also be read as a probability distribution: a bang picks a weighted random address.

static const String gTextfile

.textfile: Collects incoming messages as lines of text: each message is added to the current line and ‘cr’ ends it. Lines can be sent back one at a time or all at once, and read from or written to a text file.

static const String gDict

.dict: A key/value store shared by name. Keys nest with ‘::’ (voice::1::freq), a value is any message, and the contents are saved with the patch. A bang sends the reference ‘dictionary <name>’ that the other .dict objects take.

static const String gDictCompare

.dict.compare: Compares two named dictionaries and sends 1 when they hold the same entries, 0 when they do not. On a difference, the key paths that differ follow from the right outlet.

static const String gDictDeserialize

.dict.deserialize: Fills a named dictionary from JSON text, replacing its contents, and sends its reference. Takes a JSON object as a message, or ‘read <file>’ for a larger document.

static const String gDictGroup

.dict.group: Groups a named dictionary’s entries by value into a target dictionary, as ‘<group>::<original path>’. With a key argument, each record is grouped by the value it holds at that key.

static const String gDictIter

.dict.iter: Walks a named dictionary, sending one ‘<path> <value>’ list per entry, then a bang from the right outlet when it is done.

static const String gDictJoin

.dict.join: Merges two named dictionaries into a target dictionary: the left one’s entries, overlaid with the right one’s. Where both hold a key path, the right value wins.

static const String gDictPack

.dict.pack: Builds a named dictionary from its inlets, one inlet per key path: ‘.dict.pack synth freq gain’. The left inlet stores its value, writes the dictionary and sends its reference; the other inlets only store.

static const String gDictPrint

.dict.print: Prints a named dictionary to the engine log as indented JSON, one line per row, each line labelled with the dictionary’s name. A debugging aid with no outlets.

static const String gDictRoute

.dict.route: Sends a named dictionary’s reference out of the outlet of the first key argument it holds, or out of the rightmost outlet when it holds none. Use it to send dictionaries of different shapes to different parts of a patch.

static const String gDictSerialize

.dict.serialize: Sends a named dictionary as one line of JSON text. ‘write <file>’ saves the same JSON to a file instead, for a dictionary too large to send as a message.

static const String gDictSlice

.dict.slice: Splits a named dictionary at a key path. Entries under the path go into the slice dictionary with the path removed from their keys; all other entries go into the remainder dictionary.

static const String gDictStrip

.dict.strip: Removes every entry under a key path from a named dictionary, in place, then sends its reference. An entry stored at exactly the path is kept.

static const String gDictUnpack

.dict.unpack: Sends the values at a named dictionary’s key paths out of separate outlets, one outlet per key path argument, right to left. The inverse of .dict.pack.

static const String gArray

.array: An ordered list of values, shared by every .array with the same name in a patcher. Messages add, change, fetch and remove elements by zero-based index; a bang sends the array’s reference, which the other .array objects accept.

static const String gArrayAt

.array.at: Outputs the element at a position in a named array. Send a position to fetch it, or a list of positions to fetch several at once; a bang fetches the last position again. A position the array does not have bangs the miss outlet.

static const String gArrayChange

.array.change: Reports whether a named array has changed since it was last polled. Each bang sends 1 or 0, and on a change also sends the array’s reference, so work further down only runs when something moved.

static const String gArrayCompare

.array.compare: Compares two named arrays. A bang sends 1 when they hold the same elements in the same order, and 0 when they do not.

static const String gArrayConcat

.array.concat: Outputs the elements of two named arrays as one list: the left array followed by the right. Neither array is changed.

static const String gArrayDeserialize

.array.deserialize: Fills a named array from a JSON array such as [60,62.5,”kick”], replacing its contents. The text is parsed in the background, and the array’s reference is sent once the new contents are in place.

static const String gArrayEvery

.array.every: Tests every number in a named array with an expression. A bang sends 1 when the expression is true (non-zero) for all of them, and 0 when it is false for any.

static const String gArrayExpr

.array.expr: Evaluates an expression for each element of a named array and sends the results as one list, for example $i1 + 12 to transpose. The array itself is not changed.

static const String gArrayFill

.array.fill: Fills a named array with a number of copies of one value, replacing its contents. Use it to clear an array, or to give it a size before writing to it by position.

static const String gArrayFilter

.array.filter: Removes from a named array every element for which an expression is false (zero), keeping the rest in order. Words are removed too, because the expression only sees numbers.

static const String gArrayFlatten

.array.flatten: Outputs the elements of several named arrays as one list, in the order the arrays are named, up to 16 arrays. None of the arrays is changed.

static const String gArrayForeach

.array.foreach: Evaluates an expression for each element of a named array and sends the results one at a time, first to last, then bangs its done outlet.

static const String gArrayGroup

.array.group: Groups the equal elements of a named array. A bang sends one list per distinct value, holding that value as many times as it occurs, then bangs the done outlet.

static const String gArrayIndex

.array.index: Looks up a value in a named array. The position of the first matching element leaves the left outlet; when no element matches, the right outlet bangs.

static const String gArrayIndexmap

.array.indexmap: Reorders a named array by a list of positions: the new array holds the elements at those positions, in that order. Positions may repeat or be left out.

static const String gArrayIndexof

.array.indexof: Outputs the position of the first element of a named array that matches a value, or -1 when no element matches.

static const String gArrayInsert

.array.insert: Inserts a value or a list into a named array at a stored position, moving later elements up. Set the position on the middle inlet, then send what to insert to the left inlet.

static const String gArrayIter

.array.iter: Sends the elements of a named array one at a time, first to last, then bangs its done outlet. Use it to do something for each element.

static const String gArrayJoin

.array.join: Joins the elements of a named array into a single word, with an optional separator between them: c4 e4 g4 joined with - gives c4-e4-g4.

static const String gArrayLength

.array.length: Outputs the number of elements in a named array when it receives a bang.

static const String gArrayMap

.array.map: Applies an expression to every numeric element of a named array and writes the results back, for example $i1 + 12 to transpose. Words stay where they are.

static const String gArrayMax

.array.max: Outputs the largest number in a named array. Words are skipped.

static const String gArrayMean

.array.mean: Outputs the average of the numbers in a named array, as a float. Words are skipped.

static const String gArrayMedian

.array.median: Outputs the median of the numbers in a named array, as a float. Words are skipped, and the array itself is not reordered.

static const String gArrayMin

.array.min: Outputs the smallest number in a named array. Words are skipped.

static const String gArrayMode

.array.mode: Outputs the element that occurs most often in a named array. Words count too, and elements are compared by spelling, so 7 and 7. are different elements.

static const String gArrayPop

.array.pop: Removes the last element of a named array and outputs it. On an empty array, the empty outlet bangs instead.

static const String gArrayPush

.array.push: Appends a value or a list to the end of a named array, then sends the array’s reference. With .array.pop it makes a stack, with .array.shift a queue.

static const String gArrayRandom

.array.random: Outputs a randomly chosen element of a named array. A seed makes the sequence of picks repeat on every run.

static const String gArrayReduce

.array.reduce: Combines the numbers in a named array into one value with an expression, such as $f1 + $f2 for a sum. $f1 is the result so far and $f2 the next element.

static const String gArrayRegexp

.array.regexp: Outputs the elements of a named array that match a regular expression, as one list. When nothing matches, the right outlet bangs. The array itself is not changed.

static const String gArrayRemove

.array.remove: Removes the element at a position from a named array and outputs it; later elements move down. A position the array does not have bangs the miss outlet.

static const String gArrayReplace

.array.replace: Replaces every occurrence of a value in a named array with another value. Sends how many elements were replaced, then the array’s reference.

static const String gArrayReverse

.array.reverse: Reverses the order of the elements of a named array, then sends the array’s reference.

static const String gArrayRotate

.array.rotate: Rotates the elements of a named array by a number of positions, wrapping around the ends. Positive amounts move elements toward the end, negative toward the start.

static const String gArrayRoutepass

.array.routepass: Routes a named array by what it contains: its reference leaves the outlet of the first listed value the array holds, or the rightmost outlet when it holds none of them.

static const String gArrayScramble

.array.scramble: Shuffles the elements of a named array into a random order, and sends the order it applied so another array can be put in the same order. The same object as .array.shuffle.

static const String gArraySect

.array.sect: Outputs the elements two named arrays have in common, each once, as one list in the left array’s order. Neither array is changed.

static const String gArrayShift

.array.shift: Removes the first element of a named array and outputs it; the other elements move down one position. On an empty array, the empty outlet bangs instead.

static const String gArrayShuffle

.array.shuffle: Shuffles the elements of a named array into a random order, and sends the order it applied so another array can be put in the same order. The same object as .array.scramble.

static const String gArraySlice

.array.slice: Outputs a range of elements of a named array, from a start position up to but not including an end position. The array itself is not changed.

static const String gArraySome

.array.some: Tests the numbers in a named array with an expression. A bang sends 1 when the expression is true (non-zero) for at least one of them, and 0 when it is true for none.

static const String gArraySort

.array.sort: Sorts the elements of a named array, ascending or descending, with numbers before words. Also sends the order it applied, so another array can be put in the same order.

static const String gArraySplit

.array.split: Splits a named array in two at a position: the elements before it leave the left outlet and the rest leave the right outlet, right first. The array itself is not changed.

static const String gArrayStddev

.array.stddev: Outputs the standard deviation of the numbers in a named array, as a float. Words are skipped.

static const String gArrayStream

.array.stream: Appends incoming values to a named array and keeps only the most recent ones: a sliding window of a set size. Sends the array’s reference each time the window is full.

static const String gArraySub

.array.sub: Outputs a range of elements of a named array, both ends included; with the end before the start, the range is sent in reverse. The same object as .array.subarray.

static const String gArraySubarray

.array.subarray: Outputs a range of elements of a named array, both ends included; with the end before the start, the range is sent in reverse. The same object as .array.sub.

static const String gArrayThin

.array.thin: Removes elements of a named array that repeat the element kept before them. With a tolerance, numbers that close to it count as repeats too, which thins out a stream of values that barely change.

static const String gArrayTolist

.array.tolist: Outputs all elements of a named array as one list. An array of one element sends that element as a single int, float or symbol.

static const String gArrayTostring

.array.tostring: Outputs all elements of a named array as one text message, separated by spaces. Unlike .array.tolist, a single number is sent as text, ready for objects that work on text.

static const String gArrayTosymbol

.array.tosymbol: Joins all elements of a named array, without spaces, into one symbol: kick and .wav become kick.wav. The result is always a symbol, even when it looks like a number.

static const String gArrayTuplewise

.array.tuplewise: Combines two named arrays position by position with an expression, such as $f1 + $f2, and outputs the results as one list. The result is as long as the shorter array.

static const String gArrayUnion

.array.union: Outputs the elements held by either of two named arrays, each once, as one list. Neither array is changed.

static const String gArrayUnique

.array.unique: Outputs the elements of a named array with repeats removed, each at its first occurrence. The array itself is not changed.

static const String gArrayUnshift

.array.unshift: Inserts a value or a list at the front of a named array, moving the other elements up, then sends the array’s reference.

static const String gArrayWrap

.array.wrap: Outputs the element at a position in a named array, wrapping around: positions past the end start again at the beginning, and -1 is the last element.

static const String gDecide

.decide: A coin flip: each bang sends 0 or 1 with equal chance. Use it for random branching, fills and gating.

static const String gDrunk

.drunk: A random walk: each bang moves the value up or down by a small random step and sends it, kept within 0 to range-1. Successive values drift rather than jump.

static const String gProb

.prob: A Markov chain of weighted transitions between numbered states. Each bang jumps from the current state to a next one, chosen by weight, and sends it.

static const String gRandom

.random: Sends a random integer from 0 to range-1 on each bang, every value equally likely.

static const String gUrn

.urn: Random numbers without repeats: each bang sends a number from 0 to limit-1 that has not come out yet, like dealing from a shuffled deck. When all have been sent, the right outlet bangs.

static const String gForward

.forward: Sends what arrives to every .r with a given name, like .s, but the name can be changed with a message to the right inlet. Sends nothing until it has a destination.

static const String gPrint

.print: Writes every message that arrives to the engine log, one line each, with a name in front. Use it to watch values pass through a patch.

static const String gReceive

.r: Sends out whatever is sent to its name: by a .s or .forward in this patcher or in a patcher with the same name, by the host’s PassData, or on the named bus.

static const String gSend

.s: Sends what arrives to every .r with the same name, without a cord. It also publishes on the named bus as ‘patcher.<patcherName>.<name>’, so other patchers and the host can listen.

static const String gValue

.value: Holds a value shared by every .value with the same name. A value at the inlet is stored for all of them without being sent; a bang sends out what is stored.

static const String dAdc

~adc: The patch’s audio input. When the patcher runs as an insert effect, each outlet carries one channel of the audio it processes.

static const String dDac

~dac: The patch’s audio output. Each inlet is one output channel, passed on to the sound or insert that hosts the patcher. A patch is silent until a signal reaches this object.

static const String gInlet

.inlet: A message inlet of the subpatcher it is in. With index N, whatever the parent sends to the subpatcher’s inlet N comes out of this object, inside the subpatcher.

static const String gOutlet

.outlet: A message outlet of the subpatcher it is in. With index N, whatever arrives here leaves the subpatcher through its outlet N.

static const String patcher

patcher: A subpatcher: groups part of a patch into one object that the parent connects to by pin number. Its pins are the .inlet, .outlet, ~inlet and ~outlet objects placed inside it.

static const String dInlet

~inlet: A signal inlet of the subpatcher it is in. With index N, the signal the parent connects to the subpatcher’s inlet N comes out of this object, inside the subpatcher.

static const String dOutlet

~outlet: A signal outlet of the subpatcher it is in. With index N, the signal that arrives here leaves the subpatcher through its outlet N.

static const String gMtr

.mtr: A multi-track recorder for messages: records what arrives on each track inlet with its timing, and plays it back out of the matching outlet in the same rhythm. Each track can be recorded, played, muted and stepped on its own.

static const String gQlist

.qlist: A cue list: lines of numbers and messages played back in time. A line of numbers is sent out and its first number is the wait before the next line; a line starting with a word is sent to the receivers of that name.

static const String gSeq

.seq: Records a stream of raw MIDI bytes with its timing and plays it back. Reads and writes standard MIDI files; playback can follow its own clock, incoming ticks or a YSE domain clock.

Every constant above, in registry (type-name) order.
