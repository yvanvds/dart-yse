Arrays#

The .array family: ordered data and the operations on it.

57 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.array#

An ordered list of values, shared by every .array with the same name in a patcher. Messages add, change, fetch and remove elements by zero-based index; a bang sends the array’s reference, which the other .array objects accept.

Dart:

Obj.gArray

Kind:

Control-rate

Accepts

Range

Description

0

BANG, LIST

at most 256 elements

append, insert, set, get, delete, clear, getsize or getvalue (see the notes). A bang sends the array’s reference out of outlet 1. A refused message changes nothing.
