Collections#

Stores that hold numbers or messages for later recall.

6 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.bag#

Holds a collection of numbers that a patch adds to and removes from, such as the notes currently held down. A bang sends every number, newest first.

Dart:

Kind:

Control-rate

A number to add or remove, depending on the flag. Also bang, ‘<value> <flag>’, ‘cut’, ‘length’, ‘clear’ and ‘send <name>’.

FLOAT, INT

0 or non-zero

Non-zero: numbers on the left inlet are added. 0: they are removed. Starts at 0.

Any argument lets the same number be stored more than once. Without one, each number is held at most once.

.capture#

Records every value that reaches it, in arrival order, so a patch can be run and then asked what went past. When full, the oldest item makes room for the newest.

.coll#

Stores messages at number or symbol addresses and sends them back on request: presets, note tables, cue lists. All .coll objects with the same name share one collection.

Control-rate

at most 256 entries

A number or symbol recalls that address; ‘<number> <message>’ stores; a bang sends the entry at the pointer. Also the commands listed in the notes.

.funbuff#

Stores (x, y) pairs of ints sorted by x, and sends the y for any x: the stored y, or the one at the nearest lower x. ‘interp’ interpolates between points; ‘next’ steps through them in order.

Kind:

Control-rate

1

any int

The y for the next x on the left inlet. Sends nothing.

.table#

A fixed-size array of ints addressed by index, for wavetables, curves and step sequences. It can also be read as a probability distribution: a bang picks a weighted random address.

Dart:

Obj.gTable

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

address

FLOAT, INT, BANG, LIST

0 to size-1

With a value waiting on the right inlet, stores it here; otherwise sends the value at this address. ‘<address> <value>’ stores. A bang draws a weighted random address. Also the commands listed in the notes.

1

value

FLOAT, INT

any int

The value for the next address on the left inlet. Sends nothing.

Outlets

#

Label

Type

Range

Description

0

out

INT

any int

Stored values; the results of ‘min’, ‘max’, ‘sum’, ‘length’ and ‘getbits’; an address for bang, ‘quantile’, ‘fquantile’ and ‘inv’.

Parameters

Name

Default

Range

Description

name size

128

optional name, optional size 1-4096

A number sets the size, clamped to 1-4096. A word is a name, kept for compatibility: tables with the same name do not share values.

.textfile#

Collects incoming messages as lines of text: each message is added to the current line and ‘cr’ ends it. Lines can be sent back one at a time or all at once, and read from or written to a text file.
