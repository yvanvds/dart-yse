Dictionaries#

The .dict family: keyed, nested data.

13 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.dict#

A key/value store shared by name. Keys nest with ‘::’ (voice::1::freq), a value is any message, and the contents are saved with the patch. A bang sends the reference ‘dictionary <name>’ that the other .dict objects take.

Dart:

Obj.gDict

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

in

BANG, LIST

at most 256 entries

‘set <path> <value…>’ stores a value, ‘get <path>’ sends one, ‘delete <path>’ removes one, ‘clear’ empties the dictionary, ‘getsize’ sends the entry count and ‘getkeys’ the top-level keys. A bang sends the reference out of outlet 1.

Outlets

#

Label

Type

Range

Description

0

data

ANY

—

The value a ‘get’ fetched: one number leaves as an int or a float, anything else as a list. Also the count from ‘getsize’ and the key list from ‘getkeys’.

1

reference

LIST

—

‘dictionary <name>’ on a bang: the reference the other .dict objects accept. Silent for an unnamed dictionary.

2

miss

BANG

—

Bang when a ‘get’ names a path the dictionary does not hold.

Parameters

Name

Default

Range

Description

name

—

any identifier

The dictionary’s name. Every .dict with this name in the patcher shares one dictionary. Empty gives this object a private dictionary. Cannot be changed while the patch runs.

.dict.compare#

Compares two named dictionaries and sends 1 when they hold the same entries, 0 when they do not. On a difference, the key paths that differ follow from the right outlet.
