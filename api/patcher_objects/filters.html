Filters#

Audio-rate filters.

4 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

  • ~hp

~bp#

Bandpass filter. Passes a frequency band centered on ‘frequency’ with bandwidth shaped by ‘Q’ (resonance).

Dart:

~vcf#

Resonant bandpass filter whose center frequency is a signal, so it can sweep at audio rate. Sharpness sets how narrow the band is.

Dart:

Obj.dVcf

Kind:

DSP (audio-rate)

Inlets

#

Label

Accepts

Range

Description

0

in

BUFFER

-1.0 to 1.0

Audio input.

1

center

BUFFER

0-20000 Hz

Center frequency in Hz, as a signal. Both signal inlets must be connected for the filter to run.

2

sharpness

FLOAT

0+

How narrow the band is: higher is narrower. 0 turns filtering off.
