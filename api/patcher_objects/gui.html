GUI controls#

User-facing controls and message boxes, driven by the GUI value protocol.

25 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.function#

A breakpoint function, for drawing envelopes and curves. It stores sorted (x, y, curve) points, answers an x with the y between them, and on a bang sends the whole shape as a ramp for .line or .bline. Its points are saved with the patch.

Dart:

Obj.gFunction

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

function

FLOAT, INT, BANG, LIST

x >= 0, y in minimum-maximum, curve -1 to 1

A number is an x and sends its y; a bang sends the ramp; ‘<x> <y>’ adds a point; 3 numbers per point replace them all; ‘set’, ‘setcurve’, ‘nth’, ‘clear’ and ‘dump’ edit and query points. Edits send nothing.

Outlets

#

Label

Type

Range

Description

0

y

FLOAT

minimum-maximum

The y for an x arriving on the inlet, or for ‘nth <index>’. Always a float.

1

ramp

target time pairs

On a bang, the whole function as ‘<y> <time>’ pairs for .line or .bline: the first time is 0, each later one the distance in x from the point before.

2

dump

LIST

index x y curve

On ‘dump’, every point as ‘<index> <x> <y> <curve>’, in x order.
