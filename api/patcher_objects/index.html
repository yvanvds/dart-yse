Patcher object reference

Patcher object reference#

Every patcher object that Patcher.createObject() accepts — 305 in all — grouped by category, one page per category. The category is the one PatcherRegistry reports (PatcherObjectType.category, a PCategory), which a host editor can use to build its object palette.

Pass the type string, or the matching Obj constant shown with each entry, as the first argument to Patcher.createObject(). The pages are generated from the engine registry of the libyse this package binds, so they list exactly what createObject accepts. The upstream libYSE docs add long-form notes for many objects: libYSE patcher object reference.
