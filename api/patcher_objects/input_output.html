Input and output#

Audio in and out of the graph, named send/receive, and host-facing I/O.

7 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.forward#

Sends what arrives to every .r with a given name, like .s, but the name can be changed with a message to the right inlet. Sends nothing until it has a destination.

.print#

Writes every message that arrives to the engine log, one line each, with a name in front. Use it to watch values pass through a patch.
