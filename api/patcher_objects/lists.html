Lists#

Building lists, taking them apart and processing them.

11 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.append#

Puts a stored message after every message that arrives and sends the result as one list. Use it to add fixed trailing arguments, such as a channel number, to a computed value.

Dart:

Obj.gAppend

Kind:

Control-rate

Accepts

—

Bang emits the stored message on its own; an int, float or list is emitted with the stored message after it. With nothing stored the value is passed through as the type it arrived as.

1

FLOAT, INT, LIST

any message, at most 256 characters

Replaces the stored message, without emitting anything. A list is taken whole, an int or a float as the number it spells. An empty list clears the stored message and makes the object a pass-through; one longer than 256 characters is refused and the previous message kept.

.join#

Joins the messages held by several inlets into one list, end to end. Unlike .pack, each inlet holds a whole message of any length. .unjoin splits a list the other way.

Dart:

Obj.gJoin

Kind:

Control-rate

1

The piece in this position. Stores the whole message, whatever its length. Sends the list only when a trigger argument names this inlet. A bang sends without storing; ‘set <message>’ stores without sending.

.substitute#

Replaces every item of a message that equals the match with the replacement, anywhere in the message. A message with a replacement leaves the left outlet; one with no match leaves the right outlet unchanged.

Dart:

Obj.gSubstitute

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

in

FLOAT, INT, BANG, LIST

any

The message to edit: bang, int, float or list. A bang matches the word ‘bang’.

1

match

FLOAT, INT, LIST

any single number or symbol, at most 64 characters

Sets the item to look for, without sending anything. An empty message clears it, so everything passes out the right outlet.

2

replacement

FLOAT, INT, LIST

any single number or symbol, at most 64 characters

Sets what a matched item becomes, without sending anything. An empty message is ignored.

Splits a list into its items and sends each one out its own outlet, right to left. Each creation argument sets an outlet’s type and starting value. The reverse of .pack.

.zl#

A list processor with 31 modes: measure, reorder, pick from, search, compare, combine, accumulate or sum a list. The mode word is the first argument and can be changed with ‘mode <name>’.

Dart:

Obj.gZl

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

list

FLOAT, INT, BANG, LIST

a list, a number, bang, ‘mode <name>’, ‘zlclear’, ‘zlmaxsize <n>’, ‘zlseed <n>’

The list to process. An int or float is a list of one. A bang processes the stored list again, or takes from the store in ‘group’, ‘stream’, ‘queue’ and ‘stack’. Also takes ‘mode <name>’, ‘zlclear’, ‘zlmaxsize <n>’ and ‘zlseed <n>’, which send nothing.

1

argument

FLOAT, INT, LIST

mode dependent

The mode’s argument: an index, a count, a length or a second list, depending on the mode. Never sends anything. In ‘reg’ mode it sets the stored list instead.

Label

The result of the current mode. A result of one item is sent as an int, float or symbol; an empty result sends nothing.

1

rest

ANY

any

The second result, in the modes that have one, sent before the left outlet. Silent in the other modes.

Name

Default

Range

An optional maximum list length, then the mode word, then the mode’s argument, which the right inlet replaces later. Without a mode word the object stores lists and sends nothing.
