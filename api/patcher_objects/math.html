Math#

Arithmetic, comparison, conversion, scaling and analysis of numbers.

69 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.
