.%#

Sends the remainder of dividing the left operand by the right one, as an int. The remainder has the sign of the left operand, and a divisor of 0 sends 0.

Kind:

Control-rate

Works on whole numbers: a float on either inlet is truncated toward zero first, so 7.9 counts as 7. The remainder has the sign of the left operand, so -1 stays -1 rather than wrapping round:

.&#

Bitwise AND of two integers, sent as an int. Floats are truncated toward zero first.

Dart:

Obj.gBitAnd

Kind:

Control-rate

The bitwise objects

.&, .|, .<< and .>> work on 32-bit whole numbers and send an int. A float on either inlet is truncated toward zero first.

  • .& keeps the bits set in both operands, so .& 15 keeps the lowest four bits: 300 gives 12.

  • .| keeps the bits set in either operand.

  • .<< shifts bits up: .<< 4 turns 3 into 48. Bits shifted past the top are lost, and a count of 32 or more gives 0.

  • .>> shifts bits down and keeps the sign, so -8 shifted by 1 is -4. A count of 32 or more gives -1 for a negative number and 0 for any other.

A shift count below 0 shifts nothing. The inlets work as described under .+.

.+#

Adds two numbers. A number on the left inlet is added to the stored right operand, and the sum is sent as a float.

Dart:

Obj.gAdd

Kind:

Control-rate

Hot and cold inlets

The left inlet is hot: a number there is stored and the result is sent at once. Every other inlet is cold: it stores its number for the next result and sends nothing. The creation argument sets the right operand, which is 0 until it is given.

[.+ 10]   5 -> left inlet                    =>  15
3 -> right inlet, then 5 -> left inlet       =>  8

Every math object with more than one inlet works this way unless its notes say otherwise.

To set both operands from one message, update the cold inlet first: .trigger sends from its rightmost outlet to its leftmost, so wire its right outlet to the cold inlet and its left outlet to the hot one. .swap sends a pair in that order, and .!- and .!/ are .- and ./ with the operands the other way round.

Numbers

Ints and floats are both accepted. A bang, a list or a word is ignored, so to calculate again, send the left value again.

.+, .-, .*, ./, .!- and .!/ calculate in floats and send a float, even for two ints. A float holds whole numbers exactly only up to 16,777,216; above that, ints lose precision. Dividing by 0 sends 0. Use .% and .div for whole-number division.

.accum#

Stores a number you can replace, add to and multiply. A number on the left inlet replaces it and sends it; the middle inlet adds to it and the right inlet multiplies it, without sending.

Dart:

Obj.gAccum

Kind:

Control-rate

The middle and right inlets change the stored value without sending it, unlike the cold inlets of the other math objects, which only store an operand.

Messages

  • a number on the left inlet: replace the stored value and send it.

  • bang: send the stored value.

  • set <n>: replace the stored value without sending it.

  • add <n>: add without sending, as the middle inlet does. ft1 <n> is another spelling of the same message.

  • mult <n>: multiply without sending, as the right inlet does.

  • reset: go back to the creation argument without sending. On an .accum 1 that is 1, not 0.

A word without a number after it is ignored.

[.accum 1]   mult 2, mult 2, bang  =>  4

The stored value is a float; there is no whole-number mode, so put .round after the outlet to get whole numbers. The value never becomes infinite: it stops at about plus or minus 3.4e38, and a later multiply brings it back. An infinite or undefined number (NaN) changes nothing when it is added or multiplied, and counts as 0 when it replaces the stored value.

.anal#

Counts how often each number follows the one before it, and sends ‘<previous> <current> <count>’ for every pair it counts. Wire it into .prob to make .prob play in the style of what it heard.

Dart:

Obj.gAnal

Kind:

Control-rate

Every number after the first is counted as a pair with the number before it, and the pair leaves with its new count. The first number only becomes the one the next number is paired with.

60, 62, 60, 62  =>  60 62 1,  62 60 1,  60 62 2

Numbers are limited to 0 to limit, and floats are truncated, so with the default of 128 MIDI note numbers arrive unchanged.

Wire the outlet into .prob: each list sets the weight of that transition in .prob to the count, so .prob learns which numbers follow which and can play in the same style.

Messages

  • clear: forget the counts, but keep the last number, so the next number still forms a pair with it.

  • reset: forget the last number but keep the counts, so the next number starts a new phrase.

  • dump: send every stored pair with its count, in the order the pairs were first seen. Use it to teach a .prob created later.

Limits

At most 1024 different pairs are stored. Once the table is full, pairs already in it keep counting, and a new pair is not stored: outlet 1 bangs instead. A count stops growing at 1,048,576.

.expr#

Evaluates a C-style expression such as ‘$f1 * 2 + $f2’. The placeholders $i1-$i9 and $f1-$f9 create the inlets; the left inlet calculates and sends the result.

Dart:

Obj.gExpr

Kind:

Control-rate

Placeholders

$i1 to $i9 read an inlet as an int, truncated toward zero; $f1 to $f9 read it as a float. The number is the inlet, counted from 1 at the left. The object has as many inlets as the highest placeholder, and an inlet that is skipped, such as inlet 2 in $f1 + $f3, is there but unused. An inlet that has not received a number reads 0.

Types

Types follow C:

  • +, -, *, / and % on two ints give an int, so $i1 / $i2 is whole-number division. With a float on either side, the result is a float.

  • Comparisons (< <= > >= == !=), logic (&& || !) and bitwise operators (& | ^ << >> ~) give an int. ^ is exclusive or, not a power: use pow().

[.expr ($f1 - 32) * 5 / 9]   212  =>  100, a float

.scale#

Maps a number from the input range onto the output range and sends it as a float. An exponent other than 1 bends the mapping into a curve; numbers outside the input range map past the output range unless clip is 1.

Dart:

Obj.gScale

Kind:

Control-rate

The mapping is

n   = (value - inLow) / (inHigh - inLow)
out = outLow + (outHigh - outLow) * n ^ exponent

so an exponent above 1 starts slowly and ends fast, and one below 1 does the opposite. Below inLow, where n is negative, the curve is mirrored.

[.scale 0 127 0 1]     64  =>  0.504
[.scale 0 127 0 1 2]   64  =>  0.254

A number outside the input range maps past the output range. Set the sixth argument, clip, to 1 to limit the result to the output range instead, or use .zmap, which always limits and is always a straight line.

Either range may run from high to low. When inLow equals inHigh, the result is outLow. A result that is not a finite number sends 0. The inlets work as described under .+.

.slide#

Smooths a stream of numbers. Each number moves the output part of the way towards it: 1/slideUp of the distance when rising, 1/slideDown when falling. A slide of 1 passes numbers straight through.

Dart:

Each number moves the output (number - output) / slide closer to it. A slide of 1 jumps straight to the number; a slide of 10 covers a tenth of the remaining distance per number. The output starts at 0.

.swap#

Sends two numbers out in swapped order. A number on the left inlet leaves the right outlet, then the number stored on the right inlet leaves the left outlet.

Dart:

Kind:

Use it when two values arrive in the wrong order for the hot and cold rule (see .+). The right outlet always sends first, and everything connected to it finishes before the left outlet sends, so wire the right outlet to a cold inlet and the left outlet to the hot one:

[.swap 100]  right outlet -> right inlet of [.-]

Each number keeps its type: an int leaves as an int and a float as a float. The argument’s spelling sets its type: .swap 5 holds the int 5 and .swap 5. the float 5.

.togedge#

Bangs the left outlet when a value becomes non-zero and the right outlet when it returns to 0, and stays silent in between. A bang flips the value between zero and non-zero.

Dart:

Obj.gTogedge

Kind:

Control-rate

Only transitions are reported: 5 followed by 9 sends nothing, and neither does 0 followed by 0. The two outlets therefore take turns, never banging twice in a row from the same side, which makes them a reliable pair of note-on and note-off triggers.

0, 0.2, 0.8, 0.3, 0  =>  left bang at 0.2, right bang at the last 0

The value starts at 0, so the first non-zero number bangs the left outlet and a first 0 sends nothing. Any number other than 0 counts, fractions such as 0.5 included.

Messages

A list counts as its first number. Words and infinite or undefined numbers (NaN) are ignored. .change reports the same transitions as 1s, next to the value.
