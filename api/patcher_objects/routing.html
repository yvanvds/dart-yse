Routing#

Steering messages between inlets and outlets.

13 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.bucket#

A shift register for numbers. Each number pushes the stored values one outlet along and every outlet sends what it holds, each one a step older than the outlet to its left.

Dart:

Obj.gBucket

Kind:

Control-rate

.cycle#

Sends each message out the next outlet in turn, going back to outlet 0 after the last. Use it to deal notes across a bank of voices or to alternate between processing chains.

.decode#

Sends 1 out the selected outlet and 0 out all the others, to switch a bank of which exactly one member is on. Two more inlets override the selection: one turns every outlet on, the other mutes them all.

Dart:

Obj.gDecode

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

select

INT, BANG

0 to outlets-1

An int selects the outlet that gets 1, and every outlet sends its state. An index with no outlet is ignored. A bang sends the current state again. Outlet 0 is selected at the start.

1

secondary

INT

int

All on: an int above 0 sends 1 out every outlet; 0 or less goes back to the selection. The right inlet overrides it.

2

primary

INT

int

Mute: a non-zero int sends 0 out every outlet, whatever the other inlets say. 0 brings back the state they describe.
