Time#

Clocks, delays, ramps, rate limiting and tempo.

17 objects. Every entry is pulled directly from the engine registry, which reads the ADD_DESCRIPTION / INLET_DOC / OUTLET_DOC / PARAM_DOC macros in the libYSE source. The ~ prefix marks DSP / audio-rate objects; . marks control-rate objects. For long-form notes, see the libYSE page for this category.

.clocker#

While running, sends the time since it was started, in milliseconds, every interval (5 ms by default). With a clock bound, a second outlet sends the beats that clock has moved in the same time.

Dart:

Obj.gClocker

Kind:

Control-rate

Inlets

#

Label

Accepts

Range

Description

0

on/off

FLOAT, INT, BANG, LIST

0 or 1, bang, ‘stop’, ‘reset’, ‘clock <name>’

A non-zero number starts or restarts the clocker; 0 or ‘stop’ stops it. A bang starts a stopped clocker and resets a running one to 0, as ‘reset’ does. ‘clock <name>’ sets the clock for the beats outlet and a beat interval.

1

interval

FLOAT, INT, LIST

1+ ms, or a note value / tick count

Sets the reporting interval, in milliseconds or as a beat time. A running clocker keeps going at the new interval without restarting.

.delay#

Sends a bang a set time after it receives one: 5 ms by default, or a beat time on a domain clock. It holds one bang at a time; a new bang restarts the wait and ‘stop’ cancels it.

.tempo#

Counts notes on a named domain clock: ‘.tempo main 120 1 16’ sends 0 to 15 in sixteenth notes, over and over. Starting it sets the clock’s tempo.

0 or 1, bang, ‘stop’, ‘tempo <bpm> [<ramp>]’, ‘clock <name>’

A bang or a non-zero number starts or restarts the count from 0; 0 or ‘stop’ stops it. ‘tempo <bpm> [<ramp>]’ sets the clock’s tempo; ‘clock <name>’ changes the clock.

1

The tempo in BPM, written to the clock at once. It changes the tempo for everything on that clock.
